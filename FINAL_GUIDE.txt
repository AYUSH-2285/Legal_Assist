🎯 HOW IT WORKS (Simple)
═══════════════════════════════════════════════════════════════════════════

User Input
  ↓
  Describe situation in ANY language
  "police ne roka" / "police stopped me" / "पुलिस ने रोका"
  ↓
NORMALIZER
  Cleans up text, translates Hinglish
  ↓
MATCHER
  Detects keywords from input
  Converts keywords → semantic signals
  ↓
RESOLVER
  Matches signals → legal situations
  Calculates confidence (0-100%)
  ↓
LAW RETRIEVER
  Gets applicable laws for situation
  ↓
OUTPUT
  Shows:
  • Situation name
  • Confidence score (color-coded)
  • Applicable laws
  • What you can politely ask
  • Legal disclaimer

📞 TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════

Problem                      | Solution
────────────────────────────────────────────────────────────────────────────
"No module named PyQt5"      | pip install PyQt5==5.15.7
"JSON not found"             | Verify data/ folder in same directory
"ModuleNotFoundError"        | Check imports, verify folder structure
"Empty results"              | Try more specific keywords
"App runs slowly"            | Close other programs, check RAM
"Port already in use"        | Change port in config
"Unicode/encoding error"     | Ensure UTF-8 encoding in JSON files
