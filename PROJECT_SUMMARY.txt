🚀 QUICK START (30 seconds)
═══════════════════════════════════════════════════════════════════════════

1. Extract all files to folder: C:\LegalAssist

2. Create project structure:
   legalassist/
   ├── main.py
   ├── requirements.txt
   ├── data/
   │   ├── keywords.json
   │   ├── situations.json
   │   └── laws.json
   ├── engine/
   │   ├── normalizer.py
   │   ├── matcher.py
   │   └── resolver.py
   └── ui/
       ├── styles.py
       └── components.py

3. Open terminal in project folder

4. Run:
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python main.py

5. Application launches! ✅
